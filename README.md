# LCML

LCML 是一款现代化的 Minecraft 启动器（Windows）。本仓库用于发布安装包和收集反馈。

## 下载

在 [Releases](https://github.com/LRCZCM/LCML-release/releases/latest) 下载最新的 `LCML-<版本>.exe`，更新内容见 [更新日志](CHANGELOG.md)。

## 使用

- 支持 Windows 10 / 11（64 位），不需要安装 Java。
- 把 exe 放进一个单独的文件夹，双击运行。
- 启动器会自动检查并下载新版本，也可以下载新版 exe 替换旧的，数据都会保留。

## 反馈

在 [Issues](https://github.com/LRCZCM/LCML-release/issues/new/choose) 提交问题或建议。Issues 是公开的，上传日志前请检查有没有不想公开的信息。
