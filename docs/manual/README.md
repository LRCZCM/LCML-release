## 几个常用的词

- **实例**：一个可以单独启动的游戏，比如“1.20.1 原版”“1.21 Fabric 生存”。每个实例可以有自己的模组、存档和设置。
- **加载器**：让游戏能装模组的程序，常见的有 Fabric、Forge、NeoForge、Quilt。
- **整合包**：别人配好的一整套模组和设置，导入后直接玩。
- **版本隔离**：让每个实例的模组、存档、设置各放各的，互不影响。默认开启，建议保持开启。
