# 快照与操作历史

装错模组、更新后游戏打不开、存档被改坏了……这一章的功能就是用来“后悔”的。

## 实例快照

快照会把实例当前的样子存一份，以后可以一键恢复到那个时刻。

### 拍快照

在实例的“概览 → 实例快照”，点“拍快照”：

1. 选要存哪些内容：存档、模组、配置、资源包与光影包、截图。
2. 可以写个备注，比如“装光影前”。
3. 确认后开始拍。

相同的文件只存一份，多拍几次也不会占太多空间。

### 自动快照

下面这些操作之前，启动器会自动拍一个快照：

- 更新整合包
- 更改加载器
- 重置核心
- 升级游戏版本

不需要的话，可以在“设置 → 游戏 → 自动快照”里关掉。

### 恢复

在快照列表里点“恢复”，实例就会回到拍快照时的样子。恢复前会先自动再拍一个快照，所以恢复错了也能恢复回来。

快照只对开了版本隔离的实例有用。

## 操作历史

在启动器里安装、更新、删除模组和资源包，都会记在“操作历史”里，保留 30 天。

- 在实例的“概览 → 操作历史”里查看全部记录。
- 点“撤销”，就能把那次操作退回去。撤销本身也能再撤销。
- 一次批量操作可以整批撤销。

如果那个文件之后又被改过，就不能撤销了，这时可以用快照恢复。

## 崩溃时列出模组变化

游戏崩溃时，崩溃提示里会列出“自上次正常运行以来的变化”：新装了什么、更新了什么、删了什么。每一项旁边都有按钮，可以直接禁用、撤销更新或恢复，方便找出是哪个改动导致的崩溃。
