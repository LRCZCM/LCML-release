# 常见问题

## 没有网能玩吗？

能。游戏文件下载齐全后，断网也能启动。缺文件时，启动器会告诉你缺了哪些，联网后再启动就会自动补上。

正版账号断网时可以进单人游戏，但进不了需要正版验证的服务器。

## 提示找不到 Java 怎么办？

一般不用管，启动器会自动下载合适的 Java。下载失败的话，去“设置 → 游戏 → Java → 管理”手动下载一个，见 [Java](java.md)。

## 下载很慢或者总失败？

- 在“设置 → 下载”里换一个下载源。
- 用了代理的话，检查“设置 → 下载 → 网络代理”是否填对。
- 失败的任务可以在“下载 → 任务”里点“重试”。

## 游戏启动后马上崩溃？

看崩溃提示里的分析结果，照着建议改就行。更多方法见 [日志与崩溃](logs-diagnosis.md)。

## 我的数据存在哪里？

- **启动器数据**（设置、账号、日志）：exe 旁边的 `LCML` 文件夹。
- **游戏文件**（实例、模组、存档）：游戏目录里，默认是 exe 旁边的 `.minecraft` 文件夹。在实例列表上方可以看到当前用的游戏目录。

## 怎么搬到新电脑？

把 exe、`LCML` 文件夹和游戏目录一起拷过去就行。

正版登录信息是加密的，只能在原来的电脑上解开，所以到新电脑上要重新登录一次。

## 能用其他启动器下载的游戏吗？

能。在实例页的“管理目录”里添加其他启动器的 `.minecraft` 文件夹，里面的实例在 LCML 里可以直接启动。也可以用“从其他启动器导入”，把 MultiMC、Prism 的实例导进来。

## 关掉启动器，游戏会关吗？

不会，游戏会继续运行。但关掉之后，这次游戏的日志不会再记录，“退出后命令”不会执行，游玩时长也不会统计。

## 删错了东西怎么办？

- 删除的实例、存档、模组都在系统回收站里，可以还原。
- 模组和资源包的安装、更新、删除可以在“操作历史”里撤销。
- 拍过快照的话，可以恢复整个实例。

详见 [快照与操作历史](backup-history.md)。

## 能和朋友联机吗？

能。在“联机”页开房或加入房间，和用 HMCL、PCL 的朋友也能互通，详见 [联机](multiplayer.md)。

## 怎么反馈问题？

在 [Issues](https://github.com/LRCZCM/LCML-release/issues/new/choose) 提交，最好附上启动器日志（“设置 → 关于 → 启动器日志”）。如果是游戏崩溃，附上诊断包或日志分享链接。
