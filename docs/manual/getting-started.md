# 快速上手

## 下载和打开

1. 在 [Releases](https://github.com/LRCZCM/LCML-release/releases/latest) 下载最新的 `LCML-<版本>.exe`。
2. 新建一个空文件夹，把 exe 放进去，双击打开。

LCML 支持 Windows 10 / 11（64 位），不需要提前装 Java。

启动器的数据（设置、账号、日志等）都放在 exe 旁边的 `LCML` 文件夹里。整个文件夹拷到别的电脑，数据也跟着走。

## 第一次打开

第一次打开会先显示《用户协议与隐私说明》。勾选“我已阅读并同意”，再点“同意并继续”。不同意的话，启动器会直接退出。

之后主页会出现“开始使用 LCML”引导，按三步来就能进游戏：

1. **添加账号**
   - 买了正版：选“正版登录”，能进正版服务器、用自己的皮肤。
   - 没买或只玩单人：选“添加离线账号”，起个名字就行。
   - 详细说明见 [账号](accounts.md)。
2. **准备一个实例**
   - 点“新建实例”，选一个游戏版本安装。
   - 也可以导入别人的整合包。
   - 电脑里已有游戏版本的话，可以直接用。
   - 详细说明见 [新建实例](download-game.md)。
3. **启动游戏**：点右下角的“启动游戏”。

第一次启动要下载游戏文件，按钮上会显示进度，等它走完游戏就会打开。
